# Web Application

A simple Node.js/TypeScript web application demonstrating build automation.

## Features

- Express.js REST API
- TypeScript for type safety
- ESLint for code quality
- Automated CI/CD pipeline

## Development

```bash
# Install dependencies
npm install

# Build
npm run build

# Run
npm start

# Lint
npm run lint
```

## API Endpoints

- `GET /` - Main endpoint with system information
- `GET /health` - Health check endpoint
