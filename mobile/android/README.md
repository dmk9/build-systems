# Android Application

A simple Android application demonstrating mobile build automation.

## Features

- Android SDK 34
- Material Design
- Gradle build system
- Automated CI/CD

## Building

```bash
# Build debug APK
./gradlew assembleDebug

# Build release APK
./gradlew assembleRelease

# Run tests
./gradlew test

# Install on device
./gradlew installDebug
```

## Requirements

- Android SDK 34
- Gradle 8.2+
- JDK 11+
